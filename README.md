# الركائز الخمس للقيادة الأصيلة · The Five Pillars of Authentic Leadership

Learning Bite 2 of 4 (Reinforce) for Track A, Authentic & Inclusive Leadership, GACA Succession Development Program.

## What it is
A two-minute, three-step page:
1. **Learn (تعرّف):** the five pillars of authentic leadership.
2. **Choose (اختر):** the pillar the participant finds hardest to practise.
3. **Practise (طبّق):** a short insight and one practice for the week, tailored to the choice.

## Running it
- Offline: open `index.html` in any modern browser. Everything (fonts, logo, styles) is inside the one file.
- Online: GitHub Pages, Settings > Pages > Deploy from a branch > `main` / root.

## Collecting answers (optional)
By default the choice stays in the participant's own browser only. To collect answers centrally, paste a Microsoft Forms link into `FORM_URL` near the top of the script in `index.html`; a "سجّل إجابتك في الاستطلاع" link then appears on the practice screen.

## Notes
- Formative only. Nothing is scored or sent anywhere unless `FORM_URL` is set.
- The Co Headline and Co Text fonts are embedded as GACA brand fonts. Confirm the font licence covers web use before making the repository public.
